## 概要

Genmitsu 3018Pro（GRBL）向けに最適化された軽量CAMツールです。一般的な3018系の中華CNCをはじめ、GRBLで動くCNCに対応しています。
DXFファイルをブラウザにドロップするだけで切削用Gコードを生成します。
サーバー不要、インストール不要、HTMLファイル1枚で完結します。

## Ver.2.0 の新機能

- **ARCエンティティ対応** — 単独のARC（円弧）を読み込めるようになりました。SPLINEと同じ公差で直線近似し、チェーン最適化・工具径補正・タブの全機能に対応します（旧版はARCを無警告で読み落としていました）。
- **トレースが工具径補正を反映** — 範囲確認用トレースが、実際に刃が通る最外周（補正後エンベロープ）を描くようになりました。外側補正時の刃のはみ出しを含めてクランプ干渉を確認できます。可動域チェックも補正後の実寸で判定します。
- **CIRCLEにも保持タブ** — 円形の外形切り抜きにもタブを残せるようになりました（多角形近似方式）。円形部材の飛散を防げます。
- **Gコードの完全ASCII化** — 日本語ファイル名・レイヤー名がコメントに含まれても、出力Gコードは全文ASCIIに正規化されます（Candle誤動作対策）。

## 特長

- **DXF直接読み込み** — VectorWorks・Illustrator・Affinity対応
- **SPLINE対応** — De Boorアルゴリズムによる高精度なNURBS直線近似
- **ARC対応** — 円弧エンティティを公差ベースで直線近似（Ver.2.0）
- **チェーン最適化** — 連続した線分を自動結合してZプランジを最小化（加工時間を最大70%短縮）
- **G2円弧出力** — CIRCLE エンティティを円弧Gコードに変換
- **工具径補正** — 外形切り抜きを寸法通りに仕上げる外側／内側オフセット（マイター法）
- **ワーク配置オフセット** — 図形全体を任意の位置にシフト
- **バウンディングボックストレース** — 加工前の範囲確認用Gコードを別途生成（工具径補正を反映）
- **2.5D対応** — 彫り込み深さの異なる複数のレイヤーを設定可能。いわゆる2.5D（2D多段切削）に対応します
- **保持タブ** — 任意のレイヤーにタブを設定可能。外形切り抜きの部材飛散を防止（LINE/POLYLINE/SPLINE/ARCの閉路に加え、Ver.2.0からCIRCLEにも対応）
- **完全ASCII出力** — Candle誤動作を防ぐためGコードを全文ASCII化
- **可動域バリデーション** — 設定した機械サイズを超える場合にエラー表示（補正後エンベロープで判定）

## 使い方

1. **[ツールを開く](https://freezingdragon.github.io/CNC_web-CAM/cnc-cam.html)**
2. DXFファイルをドロップゾーンにドラッグ＆ドロップ
3. レイヤー名・切削条件・工具径補正・タブを設定
4. **◈ 解析** ボタンでDXFを読み込み
5. **⬜ トレース** で加工範囲確認用Gコードを生成
6. **⚙ Gコード生成** で切削用Gコードを生成
7. `.nc`ファイルをダウンロードしてCNCjsやCandleで実行

## DXFレイヤー設定

| レイヤー | 用途 | 図形 |
|---|---|---|
| 加工レイヤー（デフォルト：`L1`） | 切削パス | LINE / LWPOLYLINE / SPLINE / ARC / CIRCLE |
| 原点レイヤー（デフォルト：`ORIGEN`） | ワーク原点定義 | CIRCLE（1個のみ）またはSPLINE |

## 工具径補正

エンドミルの太さ（刃径）を考慮して、輪郭を寸法通りに切るための補正です。閉じたチェーンとCIRCLEに適用されます。

| 設定 | 動作 | 用途 |
|---|---|---|
| 補正なし | 刃心が輪郭をなぞる | 従来動作・線彫り |
| 外側補正 | 輪郭の外側に刃径/2オフセット | 外形切り抜き（寸法通り） |
| 内側補正 | 輪郭の内側に刃径/2オフセット | 内側くり抜き（寸法通り） |

> 開いたパス（線彫りなど）には補正は適用されません。

## 生成されるGコード

```gcode
G21        ; mmモード
G90        ; 絶対座標
M3 S10000  ; スピンドル起動
G4 P2.0    ; ウォームアップ
G0 Z5.0    ; 安全高さへ
; --- 深度反復ループ ---
G0 Z5.0
G0 X-10.0 Y-20.0
G1 Z-0.5 F150
G1 X-30.0 Y-20.0 F500
; --- 終了 ---
M5         ; スピンドル停止（最優先）
G0 Z30.0   ; 終了退避
G0 X0 Y0
M2
```

> Gコードは全文ASCIIで出力されます。コメント内の日本語ファイル名・レイヤー名はアンダースコアに置換されます（Candle誤動作対策）。

## パラメータ

| パラメータ | デフォルト | 説明 |
|---|---|---|
| 総深さ | 2.0mm | 最終切削深さ |
| 切込み/パス | 0.5mm | 1パスの切り込み量 |
| 水平送り | 500mm/min | XY方向の送り速度 |
| Z進入送り | 150mm/min | プランジ速度 |
| 移動退避高さ | 5.0mm | 線間の退避高さ |
| 終了退避高さ | 30.0mm | 加工完了時の退避高さ |
| スピンドルS値 | 10000 | 回転数（$30基準） |
| SPLINE近似誤差 | 0.05mm | 曲線・円弧の直線近似精度（ARC/円タブにも適用） |
| 工具径補正 | 補正なし | 補正なし／外側／内側 |
| X/Yオフセット | 0mm | ワーク配置オフセット |
| スケール補正 | 1.0 | Illustratorインチ問題に1/25.4を自動検出 |
